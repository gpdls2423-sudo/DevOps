1. 서버와 가상화 이해하기(서버/베어메탈/하이퍼바이저/컨테이너)
서버(Server): 술
하드웨어, 소프트웨어 어느것이든 서버라고 할 수 있음.

서버의 역할 - 요청(Request)과 응답(Response)

서버 운영방법 
- 베어메탈(bare metal) : pc 한 대에서 os 설치 후 여러 소프트웨어운영
장점: 하나의 OS에서 모든 프로그램 관리 쉽다.
단점: 프로그램 하나 해킹당하면 다른 프로그램 정보도 위험하다.
/n 프로그램 하나의 리소스(자원) 사용량이 급증할 때 나머지 프로그램도 비정상으로
작동할 가능성 있다.

	단점 해결하기 위해 가상화 기술을 통해 격리된 공간에서 소프트웨어를  실행한다.
 
가상화: 서버에 적용되는 기술
- 실제 서버가 존재하지 않더라도 마치 있는 것처럼 만드는 기술이다.(1pc, n개의 서버)
- 물리적(실제)인 컴퓨터 내에 여러 개의 논리적(가상) 컴퓨팅 환경을 만드는 기술
- 즉, 컨테이너는 서버를 효율적으로 사용하기 위한 가상화기술

가상화 기술 적용한 서버 운영방법
1. 하이퍼바이저(hypervisor): pc한 대, n개의  가상머신/ 전통적 가상화 기술
- 호스트 OS(하이퍼 바이저를 실행하는 OS, 물리적인 하드웨어 서버관리)
- 게스트 OS(가상머신 Virtual machine / 리소스 할당-CPU,메모리,디스크,네크워크)
- 여러 가상머신이 하나의 물리 하드웨어를 공유할 수 있도록 리소스를 가상화하고 관리 
프로그램 -> 시스템 콜 -> 게스트OS 커널 -> 가상 하드웨어 -> 하이퍼바이저 -> 실제하드웨어
- 각 가상머신은 자신의 게스트 OS와 커널을 가진다.



2. 컨테이너(container): pc 한 대, n개의  컨테이너
- 하이퍼바이저 가상화보다 가볍고 빠르다.
- 게스트OS커널 없이 호스트OS의 커널 기능으로 격리공간 만들 수 있다.(모든 컨테이너가 호스트 OS의 커널을 공유한다.)
- 리눅스 컨테이너의 핵심 기술로는 네임스페이스(프로세스,네크워크 등 격리), 제어그룹 기술(리소스 사용량 제어)이있다.
컨테이너 -> 시스템 콜 -> 컨테이너 엔진 -> 호스트OS커널(공유) -> 하드웨어 제어

- 장점: 빠른 속도 (가상머신보다 적은리소스),시스템 통합(쉽게접근가능),편리개발(bash명령어)
-l : list 목록
-v : verbose 상세 정보

Ubuntu 

- 새 디렉터리 만들기 : mkdir 디렉터리 이름 -> make directory
- 디렉터리 이동 : cd 디렉터리 이름 -> change directory
- 현재 디렉터리 확인: pwd -> print working directory
- 계정 추가하기 : sudo adduser 계정이름 -> Super User Do,root권한으로 명령어 실행
- 리눅스 전용 공간으로 이동: cd ~
- 패키지 목록 최신 상태로 갱신: sudo apt update -> Advenced package tool

기본 리눅스 명령어
- 파일/ 폴더 목록 확인: ls -> list 
	권한,링크,소유자,그룹,크기,수정시간,파일명 출력 : ls -l ->long listing format
	숨긴 파일까지 모두 보여주기: ls -a -> all
- 권한 수정 방법 : chmod 권한 파일이름 -> change mode
	읽기 read r 4
	쓰기 write w 2
	실행 execute 1
	ex) 750 소유자:7(4+2+1) 그룹:5(4+1) 기타:0
	ex) chmod 750 a.txt b.txt c.txt
- 디렉터리(폴더) 이동: cd 디렉터리 
	cd ~ -> 홈 디렉터리 / cd .. -> 상위 dir / cd - -> 직전 작업 dir
- 빈 디렉터리(폴더) 삭제: rmdir -> remove directory 비어있을때만 가능
- 빈 파일 생성: touch 파일.txt
- 파일에 내용넣기: echo "hello devops" > 파일.txt
- 파일 내용 확인: cat 파일.txt -> concatenate 사슬같이잇다
- 앞 파일 내용들 합쳐서 파일에 새로 기록: cat 1.txt 2.txt > s.txt
- 앞 파일 내용들 합쳐서 파일에 추가: cat 3.txt >> s.txt
	cat >와 cat >>의 차이점: cat > 은 덮어쓰기(내용 지우고 새로씀) cat >>은 이어붙이기
- 파일 복사하기: cp 복사할파일.txt 붙여쓸파일.txt
- 파일 이동하기: mv 이동파일.txt 이동할 경로/이동된파일이름.txt
